# 日本地方文化圖鑑 · 圖片庫

供 [japan-encyclopedia](https://github.com/Inari-Kira-Isla/japan-encyclopedia) 的 `atlas/` 圖鑑讀取。因圖片合計約 404MB，不放入主 repo，改放這裡並透過 jsDelivr CDN 提供。

- `img/<縣>/<類>.webp`、`img/<縣>/food_N.webp`、`img/<縣>/spot_N.webp`、`img/areas/<地區>/<類>.webp`：長邊 1280px。
- `img/t/…`：同名縮圖，長邊 480px。
- 共 1,751 張，47 都道府縣。

## 讀取網址
`https://cdn.jsdelivr.net/gh/Inari-Kira-Isla/japan-encyclopedia-assets@v1/img/hokkaido/food.webp`
請用標籤版本（`@v1`），不要用 `@main`，否則 CDN 快取更新有延遲。

## 重要聲明
- **全部圖片為 AI 生成的示意圖，不是實景照片。**
- 「吉祥物」類圖片是依當地象徵設計的原創角色，**不是官方吉祥物**。
- 圖片與文字資料一一對應，資料與可信度說明見 japan-encyclopedia 的 `atlas/README.md`。
